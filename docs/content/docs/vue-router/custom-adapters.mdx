## Reference implementations

kvant's own Vue Router adapters are the best starting point:

- Route query — `useRoute` + `router.push`/`replace`:
  [`src/vue-router/adapters/query.ts`](https://github.com/okdevme/kvant/blob/main/src/vue-router/adapters/query.ts)
- Route params — param normalization and navigation:
  [`src/vue-router/adapters/params.ts`](https://github.com/okdevme/kvant/blob/main/src/vue-router/adapters/params.ts)

For framework-agnostic adapters, see the core adapters
(`src/adapters/`), which use no framework APIs at all.
