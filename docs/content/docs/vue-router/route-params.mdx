Binds state to Vue Router route params (`route.params`) — the dynamic segments
of the path, like `/users/:id`.

Features:

- **Router-native writes** — updating a param navigates to the new path via
  `router.push`/`router.replace`.
- **Cross-hook sync** — multiple bindings of the same params stay in sync.

## Usage

Given a route like `/users/:id?tab=profile`:

```vue
<script setup lang="ts">
import { useRouteParams } from 'kvant/vue-router'
import * as kv from 'kvant/schema'

const id = useRouteParams('id', kv.number())
</script>

<template>
  <p>User #{{ id }}</p>
  <button @click="id = id! + 1">
    Next user
  </button>
</template>
```

Writing a param navigates to the corresponding URL — `/users/2?tab=profile` —
with the rest of the route (query, hash, other params) preserved.

<Callout>
Params have no "missing" representation in the path the way query keys do —
a param binding is only meaningful on routes that declare that param.
</Callout>
