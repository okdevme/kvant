Storage composables come from `kvant/vue` — Nuxt is Vue, so the same
composables work in Nuxt pages and components.

## Usage

```vue
<script setup lang="ts">
import { useLocalStorage } from 'kvant/vue'
import * as kv from 'kvant/schema'

const settings = useLocalStorage({
  theme: kv.enum(['light', 'dark']).default('light'),
  fontSize: kv.number().default(16),
})
</script>

<template>
  <button
    @click="settings = { ...settings, theme: settings.theme === 'light' ? 'dark' : 'light' }"
  >
    {{ settings.theme }}
  </button>
</template>
```

<Callout>
During SSR, `localStorage` is unavailable — the binding falls back to the
schema default (or the `fallback` option) and picks up the real value on the
client.
</Callout>

## Session storage

The same API is available for `sessionStorage` via `useSessionStorage` — state
is scoped to the tab and cleared when it closes:

```vue
<script setup lang="ts">
import { useSessionStorage } from 'kvant/vue'
import * as kv from 'kvant/schema'

const step = useSessionStorage('wizard-step', kv.number().default(0))
</script>
```
