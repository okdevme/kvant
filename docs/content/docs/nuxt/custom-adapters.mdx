## Reference implementations

kvant's own Nuxt adapters are the best starting point:

- Cookies — built on `useCookie` with SSR support:
  [`src/nuxt/adapters/cookies.ts`](https://github.com/okdevme/kvant/blob/main/src/nuxt/adapters/cookies.ts)
- Route query — `useRoute` + `navigateTo`:
  [`src/nuxt/adapters/query.ts`](https://github.com/okdevme/kvant/blob/main/src/nuxt/adapters/query.ts)
- Route params — param normalization and navigation:
  [`src/nuxt/adapters/params.ts`](https://github.com/okdevme/kvant/blob/main/src/nuxt/adapters/params.ts)

For framework-agnostic adapters, see the core adapters
(`src/adapters/`), which use no framework APIs at all.
