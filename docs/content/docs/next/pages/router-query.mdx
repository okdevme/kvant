Binds state to the Pages Router query string (`router.query`).

Features:

- **Shallow routing** — writes skip data fetching (`getServerSideProps` /
  `getStaticProps`) by default.
- **Browser history integration** — choose `push` or `replace` writes.
- **Cross-hook sync** — multiple bindings of the same keys stay in sync.

```tsx
import { useRouterQuery } from 'kvant/next/pages'
import * as kv from 'kvant/schema'
import { useThrottleFn } from 'react-use'

export function Search() {
  const [q, setQ] = useRouterQuery('q', kv.string().default(''))
  const throttledSetQ = useThrottleFn(setQ, 300)

  return <input defaultValue={q} onChange={e => throttledSetQ(e.target.value)} />
}
```

## Usage

```tsx title="pages/products.tsx"
import { useRouterQuery } from 'kvant/next/pages'
import * as kv from 'kvant/schema'

const shape = {
  q: kv.string().default(''),
  page: kv.number().default(1),
}

export default function Products() {
  const [filter, setFilter] = useRouterQuery(shape, { history: 'push' })

  return (
    <button onClick={() => setFilter(prev => ({ ...prev, page: prev.page + 1 }))}>
      Page {filter.page}
    </button>
  )
}
```

With `shallow: true` (default), writing state does not re-run
`getServerSideProps` or `getStaticProps`. Set `shallow: false` when the server
needs to re-fetch data based on the query.

Global defaults via the provider:

```tsx title="pages/_app.tsx"
import { RouterQueryOptionsProvider } from 'kvant/next/pages'

export default function App({ Component, pageProps }) {
  return (
    <RouterQueryOptionsProvider defaultOptions={{ shallow: false }}>
      <Component {...pageProps} />
    </RouterQueryOptionsProvider>
  )
}
```
