For the Pages Router, kvant provides `useRouterQuery` from
`kvant/next/pages` — it binds state to `router.query` via `next/router`.

Everything else — cookies, storage, schemas — works the same as in the App
Router and reuses the `kvant/react` hooks. See
[Local Storage](/docs/next/local-storage) and [Cookies](/docs/next/cookies).

```tsx title="pages/products.tsx"
import { useRouterQuery } from 'kvant/next/pages'
import * as kv from 'kvant/schema'

export default function Products() {
  const [filter, setFilter] = useRouterQuery({
    q: kv.string().default(''),
    page: kv.number().default(1),
  })

  return (
    <input
      value={filter.q}
      onChange={e => setFilter(prev => ({ ...prev, q: e.target.value }))}
    />
  )
}
```

Continue to [Router Query](/docs/next/pages/router-query) for the full reference.
