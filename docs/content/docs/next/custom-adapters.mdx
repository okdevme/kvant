## Reference implementations

kvant's own Next.js adapters are the best starting point:

- App Router search params — uses `useSearchParams`, `useRouter`,
  `useOptimistic` and the native History API:
  [`src/next/adapters/searchParams.ts`](https://github.com/okdevme/kvant/blob/main/src/next/adapters/searchParams.ts)
- Pages Router query — built on `next/router`:
  [`src/next/pages/adapters/query.ts`](https://github.com/okdevme/kvant/blob/main/src/next/pages/adapters/query.ts)

For framework-agnostic adapters, see the core adapters
(`src/adapters/`), which use no framework APIs at all.
