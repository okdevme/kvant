## Reference implementations

kvant's own Vue adapters are the best starting point:

- Search params — native History API + `popstate`:
  [`src/vue/adapters/searchParams.ts`](https://github.com/okdevme/kvant/blob/main/src/vue/adapters/searchParams.ts)
- Cookies — `document.cookie` + `CookieChangeEvent`:
  [`src/vue/adapters/cookies.ts`](https://github.com/okdevme/kvant/blob/main/src/vue/adapters/cookies.ts)
- Web storage — `localStorage`/`sessionStorage` + the `storage` event:
  [`src/vue/adapters/storage.ts`](https://github.com/okdevme/kvant/blob/main/src/vue/adapters/storage.ts)

The Vue adapters wrap the framework-agnostic core adapters in
`src/adapters/` and expose the snapshot as a `Ref` — useful reading if you
target multiple frameworks.
