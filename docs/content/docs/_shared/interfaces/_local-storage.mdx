title: local-storage

Binds state to [Web Storage](https://developer.mozilla.org/en-US/docs/Web/API/Web_Storage_API)
keys (`localStorage` / `sessionStorage`).

Features:

- **Cross-tab sync** — updates propagate between tabs via the `storage` event.
- **SSR-safe** — provide a `fallback` snapshot used when `window` is
  unavailable.
