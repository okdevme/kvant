Binds state to [HTTP cookies](https://developer.mozilla.org/en-US/docs/Web/HTTP/Cookies).

Features:

- **Cross-tab sync** — listens to `CookieChangeEvent` where supported.
- **Writable attributes** — cookie options (`maxAge`, `path`, `sameSite`,
  `secure`, ...) are applied on every write.
- **SSR-safe** — provide a `fallback` cookie header or snapshot used when
  `document` is unavailable.
