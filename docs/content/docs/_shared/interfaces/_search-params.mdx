title: search-params

Binds state to URL search params (`?page=2&q=react`).

Features:

- **Shareable state** — the URL fully describes the UI state.
- **Browser history integration** — choose `push` or `replace` writes.
- **Cross-hook sync** — multiple bindings of the same keys stay in sync.
