## Core principle

<switch>
  <case react>
kvant turns key-value interfaces into React state. Bind a key, pass a
schema from [`kvant/schema`](./schema), and read/write it like `useState`. The
interface (here, the URL) stays the single source of truth:
  </case>
  <case vue>
kvant turns key-value interfaces into Vue refs. Bind a key, pass a schema
from [`kvant/schema`](./schema), and read/write it like any writable `Ref`. The
interface (here, the URL) stays the single source of truth:
  </case>
</switch>

<include>./snippets/_search-input-example.mdx</include>

<switch>
  <case react>
`?q=hello` in the URL means `query` is `'hello'`. Calling `setQuery` writes back to the URL.
  </case>
  <case vue>
`?q=hello` in the URL means `query.value` is `'hello'`. Assigning to
`query.value` writes back to the URL.
  </case>
</switch>

## Options

Pass options as the last argument:

<switch>
  <case react>
```ts twoslash
import { useSearchParams } from 'kvant/react'
import * as kv from 'kvant/schema'
// ---cut---
const [query, setQuery] = useSearchParams('q', kv.string().default(''), {
  history: 'push', // add browser history entries
})
```
  </case>
  <case next>
```ts twoslash
import { useSearchParams } from 'kvant/next'
import * as kv from 'kvant/schema'
// ---cut---
const [query, setQuery] = useSearchParams('q', kv.string().default(''), {
  history: 'push', // add browser history entries
  shallow: false,  // go through the Next.js router (re-run server components)
})
```
  </case>
  <case next-pages>
```ts twoslash
import { useRouterQuery } from 'kvant/next/pages'
import * as kv from 'kvant/schema'
// ---cut---
const [query, setQuery] = useRouterQuery('q', kv.string().default(''), {
  history: 'push', // add browser history entries
  shallow: false,  // re-run data fetching (getServerSideProps)
})
```
  </case>
  <case vue>
```ts twoslash
import { useSearchParams } from 'kvant/vue'
import * as kv from 'kvant/schema'
// ---cut---
const query = useSearchParams('q', kv.string().default(''), {
  history: 'push', // add browser history entries
})
```
  </case>
  <case vue-router nuxt>
```ts twoslash
import { useRouteQuery } from 'kvant/vue-router'
import * as kv from 'kvant/schema'
// ---cut---
const query = useRouteQuery('q', kv.string().default(''), {
  history: 'push', // add browser history entries
})
```
  </case>
</switch>

## Global default options

<switch>
  <case react>
Set options once for a component subtree using the **options provider**:
  </case>
  <case vue>
Set options once for a component subtree using
the [**provide function**](https://vuejs.org/guide/components/provide-inject.html):
  </case>
</switch>

<include>./snippets/options-providers/_search-params-example.mdx</include>

<switch>
  <case react>
Nested providers merge with parent options by default (`extend: true{:ts}`).
Pass `extend={false}{:tsx}` to replace instead of merge:
  </case>
  <case vue>
Nested provides merge with parent options by default (`extend: true{:ts}`).
Pass `{ extend: false }{:ts}` to replace instead of merge:
  </case>
</switch>

<switch>
  <case react>
```tsx twoslash
import { SearchParamsOptionsProvider } from 'kvant/react'
let children: React.ReactNode
// ---cut---
<SearchParamsOptionsProvider
  defaultOptions={{ history: 'push' }}
  extend={false}
>
  {children}
</SearchParamsOptionsProvider>
```
  </case>
  <case next-pages>
```tsx twoslash
import { RouterQueryOptionsProvider } from 'kvant/next/pages'
let children: React.ReactNode
// ---cut---
<RouterQueryOptionsProvider
  defaultOptions={{ history: 'push' }}
  extend={false}
>
  {children}
</RouterQueryOptionsProvider>
```
  </case>
  <case vue>
```ts twoslash
import { provideSearchParamsOptions } from 'kvant/vue'
// ---cut---
provideSearchParamsOptions({ history: 'push' }, { extend: false })
```
  </case>
  <case vue-router nuxt>
```ts twoslash
import { provideRouteQueryOptions } from 'kvant/vue-router'
// ---cut---
provideRouteQueryOptions({ history: 'push' }, { extend: false })
```
  </case>
</switch>
