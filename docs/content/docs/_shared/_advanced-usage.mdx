## Adapters

Under the hood, every kvant binding talks to an **adapter**: a small factory
that connects a key-value interface (URL, cookies, local storage, etc.) to the state
layer.

```ts
type KvantAdapter<T, Options> = (
  keys: string[],
  options: Partial<Options>,
) => KvantAdapterInterface<T>
```

To learn more about the adapter contract and how to implement your own,
see [Custom Adapters](./custom-adapters).

## `useKvantState`

The framework-idiomatic bindings ([`useLocalStorage`](./local-storage), [`useCookies`](./cookies), etc.) are
pre-bound versions of the generic `useKvantState`, which takes an adapter
explicitly:

<switch>
  <case react>
```tsx twoslash
import { useKvantState } from 'kvant/react'
import { useCookiesKvantAdapter } from 'kvant'
import * as kv from 'kvant/schema'

const [page, setPage] = useKvantState(
  useCookiesKvantAdapter,
//^^^^^^^^^^^^^^^^^^^^^^
  'consent',
  kv.stringbool().default(false),
  { maxAge: 60 * 60 * 24 * 365, sameSite: 'lax' },
)
```
  </case>
  <case vue>
```tsx twoslash
import { useKvantState } from 'kvant/vue'
import { useCookiesKvantAdapter } from 'kvant'
import * as kv from 'kvant/schema'

const page = useKvantState(
  useCookiesKvantAdapter,
//^^^^^^^^^^^^^^^^^^^^^^
  'consent',
  kv.stringbool().default(false),
  { maxAge: 60 * 60 * 24 * 365, sameSite: 'lax' },
)
```
  </case>
</switch>

Signatures:

<switch>
  <case react>
```ts
// Single key
const [state, setState] = useKvantState(adapter, key, schema, options)

// Key map: bind several keys in one call
const [state, setState] = useKvantState(adapter, keyMap, options)
```
  </case>
  <case vue>
```ts
// Single key
const state = useKvantState(adapter, key, schema, options)

// Key map: bind several keys in one call
const state = useKvantState(adapter, keyMap, options)
```
  </case>
</switch>

## `defineKvantState`

<switch>
  <case react>
While [`useKvantState`](#usekvantstate) passes the adapter at every call site, `defineKvantState`
pre-binds an adapter once and returns a ready-to-use hook plus an
[options provider](./quick-start#global-default-options):
  </case>
  <case vue>
While [`useKvantState`](#usekvantstate) passes the adapter at every call site, `defineKvantState`
pre-binds an adapter once and returns a ready-to-use composable plus a
[provide function](./quick-start#global-default-options):
  </case>
</switch>

<switch>
  <case react>
```tsx twoslash
import { defineKvantState } from 'kvant/react'
import { useCookiesKvantAdapter } from 'kvant'

export const {
  useState: useCookies,
  OptionsProvider: CookiesOptionsProvider,
} = defineKvantState(useCookiesKvantAdapter)
```
  </case>
  <case vue>
```tsx twoslash
import { defineKvantState } from 'kvant/vue'
import { useCookiesKvantAdapter } from 'kvant'

export const {
  useState: useCookies,
  provideOptions: provideCookiesOptions,
} = defineKvantState(useCookiesKvantAdapter)
```
  </case>
</switch>

<switch>
  <case react>
As an alternative to [options providers](./quick-start#global-default-options),
you can also specify default adapter options for the entire binding:
  </case>
  <case vue>
As an alternative to [provide functions](./quick-start#global-default-options),
you can also specify default adapter options for the entire binding:
  </case>
</switch>

<switch>
  <case react>
```tsx twoslash
import { defineKvantState } from 'kvant/react'
import { useCookiesKvantAdapter } from 'kvant'

export const {
  useState: useCookies,
  OptionsProvider: CookiesOptionsProvider,
} = defineKvantState(useCookiesKvantAdapter, {
  maxAge: 60 * 60 * 24 * 365,
  sameSite: 'lax'
})
```
  </case>
  <case vue>
```tsx twoslash
import { defineKvantState } from 'kvant/vue'
import { useCookiesKvantAdapter } from 'kvant'

export const {
  useState: useCookies,
  provideOptions: provideCookiesOptions,
} = defineKvantState(useCookiesKvantAdapter, {
  maxAge: 60 * 60 * 24 * 365,
  sameSite: 'lax'
})
```
  </case>
</switch>

<switch>
  <case react>
This is exactly how the pre-bound hooks are built internally, and the recommended way to pre-configure
an adapter for your whole app.
  </case>
  <case vue>
This is exactly how the pre-bound composables are built internally, and the recommended way to pre-configure
an adapter for your whole app.
  </case>
</switch>
