## Adapters

Under the hood, every kvant binding talks to an **adapter** — a small factory
that connects a key-value interface (URL, cookies, local storage, etc.) to the state
layer:

```ts
type KvantAdapter<T, Options> = (
  keys: string[],
  options: Partial<Options>,
) => KvantAdapterInterface<T>
```

To learn more about the adapter contract and how to implement your own,
see [Custom Adapters](./custom-adapters).

## `useKvantState`

The framework-idiomatic bindings (`useSearchParams`, `useCookies`, etc.) are
pre-bound versions of the generic `useKvantState`, which takes an adapter
explicitly:

```tsx
import { useKvantState } from 'kvant/react'
import { useSearchParamsKvantAdapter, parseSearch, stringifySearch } from 'kvant'
import * as kv from 'kvant/schema'

const [page, setPage] = useKvantState(
  (keys, options) => useSearchParamsKvantAdapter(keys, {
    parseSearch,
    stringifySearch,
    ...options,
  }),
  'page',
  kv.number().default(1),
)
```

Signatures:

```ts
// Single key
const [state, setState] = useKvantState(adapter, key, schema?, options?)

// Key map — bind several keys in one call
const [state, setState] = useKvantState(adapter, keyMap, options?)
```

## `defineKvantState`

While `useKvantState` passes the adapter at every call site, `defineKvantState`
pre-binds an adapter once and returns a ready-to-use hook plus an
[options provider](./quick-start#global-default-options):

```tsx
import { defineKvantState } from 'kvant/react'
import { useCookiesKvantAdapter } from 'kvant'

export const {
  useState: useCookies,
  OptionsProvider: CookiesOptionsProvider,
} = defineKvantState(useCookiesKvantAdapter)
```

As an alternative to [options providers](./quick-start#global-default-options),
you can also specify default adapter options for the entire binding:

```tsx
import { defineKvantState } from 'kvant/react'
import { useCookiesKvantAdapter } from 'kvant'

export const {
  useState: useCookies,
  OptionsProvider: CookiesOptionsProvider,
} = defineKvantState(useCookiesKvantAdapter, {
  maxAge: 60 * 60 * 24 * 365,
  sameSite: 'lax'
})
```

This is exactly how the pre-bound hooks are built internally — and the recommended way to pre-configure
an adapter for your whole app.
