<Switch>
  <Case react>
`useSearchParams` binds state to URL search params via the History API — no
router required. The URL is the single source of truth: refreshing, sharing,
or bookmarking the link restores the exact state, and updates preserve the
URL hash and any params managed by other code.
  </Case>
  <Case next>
`useSearchParams` binds state to URL search params. The URL is the single
source of truth: refreshing, sharing, or bookmarking the link restores the
exact state. Writes use the native History API by default (`shallow`), so
no server round-trip happens — and updates are applied optimistically
inside a React transition.
  </Case>
  <Case next-pages>
`useRouterQuery` binds state to `router.query`, navigating through the
Next.js pages router. The URL is the single source of truth: refreshing,
sharing, or bookmarking the link restores the exact state. Writes are
shallow by default, so data fetching methods don't re-run — and the URL
hash is preserved.
  </Case>
  <Case react-router>
`useSearchParams` binds state to URL search params, navigating through
React Router — so writes integrate with loaders, actions, and router-aware
scroll handling. The URL is the single source of truth: refreshing,
sharing, or bookmarking the link restores the exact state.
  </Case>
  <Case vue>
`useSearchParams` binds state to URL search params via the History API — no
router required. The URL is the single source of truth: refreshing, sharing,
or bookmarking the link restores the exact state, and updates preserve the
URL hash and any params managed by other code. The composable returns a
writable `Ref`.
  </Case>
  <Case vue-router>
`useRouteQuery` binds state to the router's query parameters, using Vue
Router for navigation — so writes integrate with router guards, scroll
behavior, and history. The URL is the single source of truth: refreshing,
sharing, or bookmarking the link restores the exact state. The composable
returns a writable `Ref`.
  </Case>
  <Case nuxt>
`useRouteQuery` binds state to the router's query parameters, using the
Nuxt router for navigation — so writes integrate with middleware, scroll
behavior, and history. The URL is the single source of truth: refreshing,
sharing, or bookmarking the link restores the exact state. The composable
returns a writable `Ref`.
  </Case>
</Switch>
