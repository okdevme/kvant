<switch>
  <case react vue>
`useCookies` binds state to a cookie. Cookies **can be read by server**,
which makes them ideal for values that affect SSR — locale, theme, feature flags.
Changes are picked up across tabs via the [Cookie Store API](https://developer.mozilla.org/en-US/docs/Web/API/Cookie_Store_API)
where available.
  </case>
  <case nuxt>
`useCookies` binds state to a cookie, built on Nuxt's SSR-aware
[`useCookie`](https://nuxt.com/docs/api/composables/use-cookie) — cookies
work on both server and client with no fallback setup: the server reads the
request's `Cookie` header and the value is serialized into the payload for
hydration.
  </case>
</switch>

<switch>
  <case react>
```tsx
import { useCookies } from 'kvant/react'
import * as kv from 'kvant/schema'

export function LocaleSelect() {
  const [locale, setLocale] = useCookies('locale', kv.string().default('en'))

  return (
    <select value={locale} onChange={e => setLocale(e.target.value)}>
      <option value="en">English</option>
      <option value="de">Deutsch</option>
    </select>
  )
}
```
  </case>
  <case vue>
```vue
<script setup lang="ts">
import { useCookies } from 'kvant/vue'
import * as kv from 'kvant/schema'

const locale = useCookies('locale', kv.string().default('en'))
</script>

<template>
  <select v-model="locale">
    <option value="en">English</option>
    <option value="de">Deutsch</option>
  </select>
</template>
```
  </case>
  <case nuxt>
```vue
<script setup lang="ts">
import { useCookies } from 'kvant/nuxt'
import * as kv from 'kvant/schema'

const locale = useCookies('locale', kv.string().default('en'))
</script>

<template>
  <select v-model="locale">
    <option value="en">English</option>
    <option value="de">Deutsch</option>
  </select>
</template>
```
  </case>
</switch>

Key maps work too:

<switch>
  <case react>
```tsx
const [prefs, setPrefs] = useCookies({
  locale: kv.string().default('en'),
  theme: kv.enum(['light', 'dark']).default('light'),
})

setPrefs(prev => ({ ...prev, theme: 'dark' }))
```
  </case>
  <case vue>
```ts
const prefs = useCookies({
  locale: kv.string().default('en'),
  theme: kv.enum(['light', 'dark']).default('light'),
})

prefs.value = { ...prefs.value, theme: 'dark' }
prefs.value.theme = 'dark' // deeply reactive!
```
  </case>
</switch>
