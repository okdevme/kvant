---
title: Local Storage
---

`useLocalStorage` binds state to a [`localStorage`](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage) entry. Values persist
across reloads, and changes **sync across tabs** via the [`storage` event](https://developer.mozilla.org/en-US/docs/Web/API/Window/storage_event).

<switch>
  <case react>
```tsx twoslash
import { useLocalStorage } from 'kvant/react'
import * as kv from 'kvant/schema'

export function ThemeToggle() {
  const [theme, setTheme] = useLocalStorage(
    'theme',
    kv.enum(['light', 'dark']).default('light'),
  )

  return (
    <button onClick={() => setTheme(t => (t === 'light' ? 'dark' : 'light'))}>
      Theme: {theme}
    </button>
  )
}
```
  </case>
  <case vue>
```vue twoslash
<script setup lang="ts">
import { useLocalStorage } from 'kvant/vue'
import * as kv from 'kvant/schema'

const theme = useLocalStorage('theme', kv.enum(['light', 'dark']).default('light'))
</script>

<template>
  <button @click="theme = theme === 'light' ? 'dark' : 'light'">
    Theme: {{ theme }}
  </button>
</template>
```
  </case>
</switch>

Key maps work too:

<switch>
  <case react>
```tsx twoslash
import { useLocalStorage } from 'kvant/react'
import * as kv from 'kvant/schema'
// ---cut---
const [prefs, setPrefs] = useLocalStorage({
  theme: kv.enum(['light', 'dark']).default('light'),
  fontSize: kv.number().default(16),
})

setPrefs(prev => ({ ...prev, fontSize: prev.fontSize + 1 }))
```
  </case>
  <case vue>
```tsx twoslash
import { useLocalStorage } from 'kvant/vue'
import * as kv from 'kvant/schema'
// ---cut---
const prefs = useLocalStorage({
  theme: kv.enum(['light', 'dark']).default('light'),
  fontSize: kv.number().default(16),
})

prefs.value = { ...prefs.value, fontSize: prefs.value.fontSize + 1 }
prefs.value.fontSize += 1 // deeply reactive!
```
  </case>
</switch>

## Session storage

The same API exists for [`sessionStorage`](https://developer.mozilla.org/en-US/docs/Web/API/Window/sessionStorage) via `useSessionStorage`.
It is scoped to the current tab, cleared when the tab closes, and not shared across tabs:

<switch>
  <case react>
```tsx twoslash
import * as kv from 'kvant/schema'
// ---cut---
import { useSessionStorage } from 'kvant/react'

const [draft, setDraft] = useSessionStorage('draft', kv.string().default(''))
```
  </case>
  <case vue>
```tsx twoslash
import * as kv from 'kvant/schema'
// ---cut---
import { useSessionStorage } from 'kvant/vue'

const draft = useSessionStorage('draft', kv.string().default(''))
```
  </case>
</switch>
