---
title: throttle-warning
---

<Callout type="warn">
**Throttle/debounce is not built in yet.** kvant writes to the URL/history on
every state update. For rapidly changing values (text inputs, sliders, drag
interactions), either avoid binding state directly, or wrap the kvant state in
your own throttle/debounce mechanism. First-party support is planned for a
future release.
</Callout>
