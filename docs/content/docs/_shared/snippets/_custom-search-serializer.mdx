## Custom search serializer

The default serializer uses [`URLSearchParams`](https://developer.mozilla.org/en-US/docs/Web/API/URLSearchParams), so values are flat strings
(or repeated keys for arrays). For nested structures, plug in a custom
parser/serializer, for example [`qs`](https://github.com/ljharb/qs), by
defining your own binding (see [Advanced Usage](./advanced-usage)):

<switch>
  <case react>
```ts twoslash title="lib/search-params.ts"
import { useSearchParamsKvantAdapter } from 'kvant'
import { defineKvantState } from 'kvant/react'
import qs from 'qs'

export const {
  useState: useSearchParams,
  OptionsProvider: SearchParamsOptionsProvider
} = defineKvantState(
  (keys, options) => useSearchParamsKvantAdapter(keys, {
    parseSearch: search => qs.parse(search, { ignoreQueryPrefix: true }),
    stringifySearch: values => qs.stringify(values, { encodeValuesOnly: true }),
    ...options,
  }),
)
```
  </case>
  <case next>

With `qs` handling (de)serialization, the full power of [`kvant/schema`](./schema)
opens up inside the URL: objects, nested arrays, and more.

<switch>
  <case react>
```ts twoslash
import { useSearchParamsKvantAdapter } from 'kvant'
import { defineKvantState } from 'kvant/react'
import qs from 'qs'
import * as kv from 'kvant/schema'

export const {
  useState: useSearchParams,
  OptionsProvider: SearchParamsOptionsProvider
} = defineKvantState(
  (keys, options) => useSearchParamsKvantAdapter(keys, {
    parseSearch: search => qs.parse(search, { ignoreQueryPrefix: true }),
    stringifySearch: values => qs.stringify(values, { encodeValuesOnly: true }),
    ...options,
  }),
)
// ---cut---
const [filters, setFilters] = useSearchParams(
  'filters',
  kv.object({
    tags: kv.array(kv.string()).default([]),
    range: kv.tuple([kv.number(), kv.number()]).optional(),
  }).prefault({}),
)
// URL: ?filters[tags][0]=a&filters[tags][1]=b&filters[range][0]=1&filters[range][1]=9
```
  </case>
  <case vue>
