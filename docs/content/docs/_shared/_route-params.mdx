---
title: Route Params
---

<switch>
  <case vue-router>
`useRouteParams` binds state to the **route params** — the dynamic
segments of the route (`/users/:id`). Useful when an identifier belongs in
the path rather than the query string.
  </case>
  <case nuxt>
`useRouteParams` binds state to the **route params** — the dynamic
segments of the route (`/users/[id]`). Useful when an identifier belongs in
the path rather than the query string.
  </case>
</switch>

<switch>
  <case vue-router>
```vue
<script setup lang="ts">
import { useRouteParams } from 'kvant/vue-router'
import * as kv from 'kvant/schema'

// Route: /users/:id
const id = useRouteParams('id', kv.string())
</script>

<template>
  <p>User #{{ id }}</p>
</template>
```
  </case>
  <case nuxt>
```vue
<script setup lang="ts">
import { useRouteParams } from 'kvant/nuxt'
import * as kv from 'kvant/schema'

// Route: /users/[id]
const id = useRouteParams('id', kv.string())
</script>

<template>
  <p>User #{{ id }}</p>
</template>
```
  </case>
</switch>

Writing a param navigates to the updated path:

```ts
id.value = '42' // navigates to /users/42
```

<Callout type="warn">
Route params are only as writable as your route definitions allow. Writing
a param not present in the current route's pattern has no effect on the
path; for values that don't belong in the path, prefer
[query parameters](./route-query).
</Callout>

Repeatable params work too:

<switch>
  <case vue-router>
```ts
// Route: /docs/:slug*
const slug = useRouteParams('slug', kv.string().array().default([]))
```
  </case>
  <case nuxt>
```ts
// Route: /docs/[[...slug]]
const slug = useRouteParams('slug', kv.string().array().default([]))
```
  </case>
</switch>

Key maps bind several params at once:

<switch>
  <case vue-router>
```ts
// Route: /:org/:repo
const route = useRouteParams({
  org: kv.string(),
  repo: kv.string(),
})
```
  </case>
  <case nuxt>
```ts
// Route: /[org]/[repo]
const route = useRouteParams({
  org: kv.string(),
  repo: kv.string(),
})
```
  </case>
</switch>
