## Why schemas?

Storage values are untyped: URLs, cookies, web
storage — all hold plain strings. A schema defines the contract between the stored
representation and your typed state:

- `parse(value)`: storage to state. Called on reads.
- `encode(value)`: state to storage. Called on writes.

Without a schema, values pass through as-is.
With one, <switch>
  <case react vue>`useSearchParams('count', kv.number()){:ts}`</case>
  <case next-pages>`useRouterQuery('count', kv.number()){:ts}`</case>
  <case vue-router nuxt>`useRouteQuery('count', kv.number()){:ts}`</case>
</switch> hands you a real `number`
and writes a canonical string back to the URL.

## Why `kvantjs/schema`?

`kvantjs/schema` is a small schema library purpose-built to work with type-constrained key-value interfaces.

If you know [Zod](https://zod.dev), you already know most of the API:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.int().min(1).default(1)
```

What makes it different from Zod & friends:

- **Bidirectional.** Every schema both parses *and* encodes. Validation-only
  libraries can't serialize your state back to a string.
- **Encodes to serializable values.** Guarantees that any valid state value
  can be stored in type-constrained key-value interfaces.
- **Smart casting.** Schemas accept loosely-typed raw input and cast it:
  `'42'` becomes `42`, `'true'` becomes `true`, etc.
  There is no strict "input must already be a specific type" stage.
- **No errors by design.** Schemas never throw. Invalid input parses to
  `undefined` (or your [default](#default)), which is exactly the resilience you want
  when reading user-editable URLs and cookies.

`kvantjs/schema` is framework-agnostic. Import it anywhere:

```ts
import * as kv from 'kvantjs/schema'
```

`kvantjs/schema` is not tied to kvant hooks. It works anywhere you need
bidirectional parsing or smart casting, including server-side code:

<switch>
  <case react vue vue-router>
```ts twoslash title="server-side or build-time usage (e.g. an API handler)"
import * as kv from 'kvantjs/schema'
import { parseSearch } from 'kvantjs'

const querySchema = kv.object({
  q: kv.string().default(''),
  page: kv.index().default(0),
})

export function parseProductsQuery(url: URL) {
  return querySchema.parse(
    parseSearch(url.search)
  )
}
```
  </case>
  <case next>
```tsx twoslash title="app/products/page.tsx"
import * as kv from 'kvantjs/schema'

const searchParamsSchema = kv.object({
  q: kv.string().default(''),
  page: kv.index().default(0),

export default async function Page({
  searchParams,

  searchParams: Promise<Record<string, string | string[] | undefined>>

  const { q, page } = searchParamsSchema.parse(await searchParams)!
  // ...
}
```
  </case>
  <case next-pages>
```ts twoslash title="pages/products.tsx"
import * as kv from 'kvantjs/schema'
import type { GetServerSideProps } from 'next'

const querySchema = kv.object({

  // ...
  return { props: { /* ... */ } }
}
```
  </case>
  <case react-router>

  </case>
  <case nuxt>

## API

### Strings

#### `kv.string()` [#string]

Parses raw input via [`String()` constructor](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/String).

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.string().parse('hello')  // 'hello'
kv.string().parse(42)       // '42'
kv.string().parse(null)     // undefined
```

Chainable filters:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.string().min(3)            // rejects strings shorter than 3 chars
kv.string().max(20)           // rejects strings longer than 20 chars
kv.string().length(8)         // exact length
kv.string().nonempty()        // alias of .min(1)
kv.string().regex(/^[a-z]+$/)
kv.string().startsWith('sk_')
kv.string().endsWith('.json')
kv.string().includes('@')
kv.string().uppercase()       // rejects non-uppercase strings
kv.string().lowercase()       // rejects non-lowercase strings
```

<Callout type="warn">
Chained constraints like `.min()`, `.regex()`, are **filters**,
not validators: a rejected value falls back to `undefined` (or your [default](#default)) rather than
producing an error. This is a deliberate difference from Zod: `kvantjs/schema`
never fails, because the storage it reads (URLs, cookies) is user-editable and
must degrade gracefully.
</Callout>

Mutating transforms:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.string().trim()
kv.string().toLowerCase()
kv.string().toUpperCase()
kv.string().normalize() // Unicode normalization
kv.string().slice(0, 8)
```

<Callout>
Mutating transforms are applied in both directions (parse and encode),
so the stored value is always canonical.
</Callout>

#### `kv.uriComponent()` [#uricomponent]

Decodes with [`decodeURIComponent()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/decodeURIComponent),
encodes with [`encodeURIComponent()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/encodeURIComponent).
Malformed escape sequences parse to `undefined`.

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.uriComponent().parse('Hello%20World%21') // 'Hello World!'
kv.uriComponent().encode('Hello World!')    // 'Hello%20World!'
```

#### `kv.base64()` [#base64]

Decodes/encodes Base64 strings ([`atob()`](https://developer.mozilla.org/en-US/docs/Web/API/Window/atob)/[`btoa()`](https://developer.mozilla.org/en-US/docs/Web/API/Window/btoa)).
Invalid Base64 parses to `undefined`.

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.base64().parse('SGVsbG8=') // 'Hello'
kv.base64().encode('Hello')   // 'SGVsbG8='
```

#### `kv.base64url()` [#base64url]

URL-safe Base64 ([RFC 4648 §5](https://datatracker.ietf.org/doc/html/rfc4648#section-5)):
`-`/`_` alphabet, no padding. Ideal for URLs and cookies.

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.base64url().parse('SGVsbG8') // 'Hello'
kv.base64url().encode('Hello')  // 'SGVsbG8'
```

### Numbers

#### `kv.number()`

Smart-casts raw input with [`Number.parseFloat()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Number/parseFloat).
`NaN` and non-finite values parse to `undefined`.

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.number().parse('3.14')  // 3.14
kv.number().parse('abc')   // undefined
kv.number().encode(3.14)   // 3.14
```

Chainable filters:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.number().gt(0)
kv.number().gte(0)         // alias: .min(0)
kv.number().lt(0)
kv.number().lte(0)         // alias: .max(0)
kv.number().positive()
kv.number().nonnegative()
kv.number().negative()
kv.number().nonpositive()
kv.number().multipleOf(5)  // alias: .step(5)
```

Mutating transforms:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.number().clamp(0, 100)  // clamps into [min, max], .clamp(max) clamps above only
kv.number().floor()
kv.number().ceil()
kv.number().round()
kv.number().trunc()
```

#### `kv.int()` [#int]

An integer schema: parses like [`kv.number()`](#number), then truncates toward zero and
clamps into the safe integer range.

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.int().parse('42.9')  // 42 (truncated)
kv.int().parse('abc')   // undefined
```

#### `kv.index()` [#index]

Zero-based state mapped to a **one-based** stored value. Useful for page
numbers, where `?page=1` should read as index `0`.

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.index().parse('1')  // 0
kv.index().parse('3')  // 2
kv.index().encode(0)   // 1
```

Negative state values are clamped to `0`, stored values below `1` clamp to `0`
in state.

#### `kv.hex()` [#hex]

Hexadecimal string to an integer. Encodes with an even digit count.

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.hex().parse('ff')   // 255
kv.hex().encode(255)   // 'ff'
kv.hex().encode(10)    // '0a'
```

### Booleans

#### `kv.boolean()` [#boolean]

Parses truthiness via [`Boolean()` constructor](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Boolean/Boolean).
This means the string `'false'` parses to `true`. For string representations of booleans, use
[`kv.stringbool()`](#stringbool) instead.

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.boolean().parse('anything') // true
kv.boolean().parse('')         // false
kv.boolean().parse(1)          // true
kv.boolean().parse(0)          // false
```

#### `kv.stringbool()` [#stringbool]

Parses common string representations of booleans. Case-insensitive by default.

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.stringbool().parse('true')  // true
kv.stringbool().parse('yes')   // true
kv.stringbool().parse('0')     // false
kv.stringbool().parse('maybe') // undefined
kv.stringbool().encode(true)   // 'true'
kv.stringbool().encode(false)  // 'false'
```

Defaults:
- Truthy values: `'true'`, `'1'`, `'yes'`, `'on'`, `'y'`, `'enabled'`.
- Falsy values: `'false'`, `'0'`, `'no'`, `'off'`, `'n'`, `'disabled'`.

Customize the recognized strings:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
const onOffSchema = kv.stringbool({
  truthy: ['on'],
  falsy: ['off'],
  case: 'sensitive', // default: 'insensitive'
})
```

When encoding, the **first entry** of each list is used:

```ts twoslash
import * as kv from 'kvantjs/schema'
const onOffSchema = kv.stringbool({
  truthy: ['on'],
  falsy: ['off'],
  case: 'sensitive', // default: 'insensitive'
})
// ---cut---
onOffSchema.encode(true) // 'on'
```

### Enums

#### `kv.enum()` [#enum]

Validates against a fixed set of string values. Accepts an array or an
enum-like object (including [TypeScript Enums](https://www.typescriptlang.org/docs/handbook/enums.html)):

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
const sortSchema = kv.enum(['newest', 'oldest', 'popular'])
// or: kv.enum(SortOrder) / kv.enum({ Newest: 'newest', ... })

sortSchema.parse('newest')  // 'newest'
sortSchema.parse('random')  // undefined
```

Extract the schema's values as an enum-like object:

```ts twoslash
import * as kv from 'kvantjs/schema'
const sortSchema = kv.enum(['newest', 'oldest', 'popular'])
// ---cut---
const values = sortSchema.enum
//    ^?
```

Derive narrower enums:

```ts twoslash
import * as kv from 'kvantjs/schema'
const sortSchema = kv.enum(['newest', 'oldest', 'popular'])
// ---cut---
const extracted = sortSchema.extract(['newest', 'oldest'])
//    ^?

const excluded = sortSchema.exclude(['oldest'])
//    ^?
```

### Unknowns

#### `kv.unknown()` [#unknown]

Pass any value through unchanged. Inferred type is `unknown`.

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
const value = kv.unknown().parse({ a: 1 }) // { a: 1 }
//    ^?
```

#### `kv.any()` [#any]

Pass any value through unchanged. Inferred type is `any`.

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
const value = kv.any().parse({ a: 1 }) // { a: 1 }
//    ^?
```

<Callout type="warn">
Because unknown values are not parsed, `kv.unknown()` and `kv.any()` cannot guarantee
they are serializable. Prefer using an explicit schema if you plan to use it for encoding.
</Callout>

### Dates

Date schemas parse stored strings/numbers into [`Date`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date)
objects and serialize them back.

Chainable filters:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.isoDatetimeToDate().min(new Date('2020-01-01'))
kv.isoDatetimeToDate().max(new Date('2030-01-01'))
```

Mutating transforms:
```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.isoDatetimeToDate().clamp(new Date('2020-01-01'), new Date('2030-01-01'))
```

#### `kv.isoDatetimeToDate()` [#isodatetime]

Full ISO 8601 datetime strings to `Date`.

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.isoDatetimeToDate().parse('2026-02-15T10:30:00.000Z')            // Date (2026-02-15T10:30:00.000Z)
kv.isoDatetimeToDate().encode(new Date('2026-02-15T10:30:00.000Z')) // '2026-02-15T00:00:00.000Z'
kv.isoDatetimeToDate().parse('not a date')                          // undefined
```

#### `kv.isoDateToDate()` [#isodatetodate]

Shorter ISO format `YYYY-MM-DD` to `Date`.

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.isoDateToDate().parse('2026-02-15T10:30:00.000Z')            // Date (2026-02-15T00:00:00.000Z)
kv.isoDateToDate().encode(new Date('2026-02-15T10:30:00.000Z')) // '2026-02-15'
```

#### `kv.isoYearMonthToDate()` [#isoyearmonthtodate]

Shorter ISO format `YYYY-MM` to `Date`.

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.isoYearMonthToDate().parse('2026-02-15T10:30:00.000Z')            // Date (2026-02-01T00:00:00.000Z)
kv.isoYearMonthToDate().encode(new Date('2026-02-15T10:30:00.000Z')) // '2026-02'
```

#### `kv.isoYearToDate()` [#isoyeartodate]

Shorter ISO format `YYYY` to `Date`.

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.isoYearToDate().parse('2026-02-15T10:30:00.000Z')            // Date (2026-01-01T00:00:00.000Z)
kv.isoYearToDate().encode(new Date('2026-02-15T10:30:00.000Z')) // '2026'
```

#### `kv.epochMillisToDate()` [#epochmillistodate]

Unix timestamps to `Date`.

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.epochMillisToDate().parse('1771151400000')          // Date (2026-02-15T10:30:00.000Z)
kv.epochMillisToDate().encode(new Date(1771151400000)) // 1771151400000
```

#### `kv.epochSecondsToDate()` [#epochsecondstodate]

Unix timestamps **in seconds** to `Date`.

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.epochSecondsToDate().parse('1771151400')             // Date (2026-02-15T10:30:00.000Z)
kv.epochSecondsToDate().encode(new Date(1771151400000)) // 1771151400
```

### Composites

#### `kv.object(shape)` [#object]

Parses plain objects property-by-property. Each property schema receives the
raw value at its key.

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
const filtersSchema = kv.object({
  q: kv.string().default(''),
  page: kv.index().default(0),
  tags: kv.array(kv.string()).default([]),
})

const filters = filtersSchema.parse({ q: 'shoes', page: '2' }) // { q: 'shoes', page: 1 }
//    ^?
```

<Callout>
Properties that parse to `undefined` are **kept as explicit
`undefined`** if the key was present in the input, and omitted otherwise.
</Callout>

Access the property schemas via `.shape`:

```ts twoslash
import * as kv from 'kvantjs/schema'
const filtersSchema = kv.object({
  q: kv.string().default(''),
  page: kv.index().default(0),
  tags: kv.array(kv.string()).default([]),
})
// ---cut---
const qSchema = filtersSchema.shape.q
//    ^?
```

Get an [enum schema](#enum) of the property keys via `.keyof()`:

```ts twoslash
import * as kv from 'kvantjs/schema'
const filtersSchema = kv.object({
  q: kv.string().default(''),
  page: kv.index().default(0),
  tags: kv.array(kv.string()).default([]),
})
// ---cut---
const keys = filtersSchema.keyof() // like kv.enum(['q', 'page', 'tags'])
//    ^?

keys.parse('page')   // 'page'
keys.parse('random') // undefined
```

Merge new properties into the object via `.extend()`. Later schemas
override existing keys:

```ts twoslash
import * as kv from 'kvantjs/schema'
const filtersSchema = kv.object({
  q: kv.string().default(''),
  page: kv.index().default(0),
  tags: kv.array(kv.string()).default([]),
})
// ---cut---
const filters = filtersSchema.extend({ sort: kv.enum(['asc', 'desc']) }).parse({})
//    ^?
```

Like `.extend()`, but restrict overriding keys to schemas with compatible
input/output types, via `.safeExtend()`:

```ts twoslash
import * as kv from 'kvantjs/schema'
const filtersSchema = kv.object({
  q: kv.string().default(''),
  page: kv.index().default(0),
  tags: kv.array(kv.string()).default([]),
})
// ---cut---
filtersSchema.safeExtend({ q: kv.string().min(1).default('') })

// @errors: 2322
filtersSchema.safeExtend({ q: kv.number() })
```

Pick a subset of properties via `.pick()`:

```ts twoslash
import * as kv from 'kvantjs/schema'
const filtersSchema = kv.object({
  q: kv.string().default(''),
  page: kv.index().default(0),
  tags: kv.array(kv.string()).default([]),
})
// ---cut---
const filters = filtersSchema.pick({ q: true, tags: true }).parse({})
//    ^?
```

Omit properties via `.omit()`:

```ts twoslash
import * as kv from 'kvantjs/schema'
const filtersSchema = kv.object({
  q: kv.string().default(''),
  page: kv.index().default(0),
  tags: kv.array(kv.string()).default([]),
})
// ---cut---
const filters = filtersSchema.omit({ page: true }).parse({})
//    ^?
```

Make properties optional via `.partial()`:

```ts twoslash
import * as kv from 'kvantjs/schema'
const filtersSchema = kv.object({
  q: kv.string().default(''),
  page: kv.index().default(0),
  tags: kv.array(kv.string()).default([]),
})
// ---cut---
const allOptional = filtersSchema.partial().parse({})
//    ^?

const qOptional = filtersSchema.partial({ q: true }).parse({})
//    ^?
```

Define a schema for unrecognized keys via `.catchall()`. Instead of being
stripped, unknown keys are parsed (and encoded) through it:

```ts twoslash
import * as kv from 'kvantjs/schema'
const filtersSchema = kv.object({
  q: kv.string().default(''),
  page: kv.index().default(0),
  tags: kv.array(kv.string()).default([]),
})
// ---cut---
const withExtras = filtersSchema.catchall(kv.string())

const filters = withExtras.parse({ q: 'shoes', color: 'red' }) // { q: 'shoes', page: 0, tags: [], color: 'red' }
//    ^?
```

Unknown keys are **stripped** by default. If you need to keep the unknown keys, use `kv.looseObject()`:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
const filtersSchema = kv.looseObject({
  q: kv.string().default(''),
  page: kv.index().default(0),
})

const filters = filtersSchema.parse({ q: 'shoes', color: 'red' }) // { q: 'shoes', page: 0, color: 'red' }
//    ^?

const encoded = filtersSchema.encode({ q: 'shoes', page: 1, color: 'red' }) // { q: 'shoes', page: 2, color: 'red' }
//    ^?
```

<Callout type="warn">
Because unknown values are not parsed, `kv.looseObject()` cannot guarantee
they are serializable. Prefer `.catchall()` with an explicit
schema if you plan to use it for encoding.
</Callout>

#### `kv.array(schema)` [#array]

Wraps a schema into an array of itself:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
const numbersSchema = kv.array(kv.number())
// or: kv.string().array()

const numbers = numbersSchema.parse(['1', '2', '3']) // [1, 2, 3]
//    ^?
```

A single (non-repeated) raw value is
wrapped into a one-item array, handy for interfaces that may repeat a key,
like search params (`?numbers=3.14`):

```ts
numbersSchema.parse('3.14') // [3.14]
```

`kv.array()` automatically filters out elements that parse to `undefined` from the output array by default.
If you need to preserve `undefined` elements, use `kv.looseArray()` instead:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
const numbers = kv.array(kv.number()).parse(['1', 'invalid', '3']) // [1, 3]
//    ^?

const looseNumbers = kv.looseArray(kv.number()).parse(['1', 'invalid', '3']) // [1, undefined, 3]
//    ^?
```

Alternatively you can reject the whole array if any element parses to `undefined`
with a simple [`.transform()`](#transform):

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
const numbersSchema = kv.looseArray(kv.number())
  .transform(arr => arr?.every(i => i !== undefined) ? arr : undefined)

const numbers = numbersSchema.parse(['1', 'invalid', '3']) // undefined
//    ^?
```

Chainable filters:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.array(kv.string()).nonempty()   // alias: .min(1)
kv.array(kv.string()).min(1)
kv.array(kv.string()).max(5)
kv.array(kv.string()).length(3)
```

Mutating transforms:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.array(kv.string()).slice(0, 10)
```

#### `kv.tuple(items, rest?)` [#tuple]

Fixed-length array with per-position schemas. Trailing items whose schema
parses to `undefined` are omitted from the output.

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
const rangeSchema = kv.tuple([kv.number().default(0), kv.number()])

const range = rangeSchema.parse(['0', '100']) // [0, 100]
//    ^?
```

Variadic rest argument:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
const pathSchema = kv.tuple([kv.string().default('users')], kv.number())
//                                                          ^^^^^^^^^^^

const path = pathSchema.parse(['users', '42', '7'])
//    ^?
```

#### `kv.set(schema)` [#set]

A [`Set`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set)
of the inner schema's outputs. Parses from single or repeated raw values. Encodes to an array.

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
const idsSchema = kv.set(kv.int())

const ids = idsSchema.parse(['1', '2', '2']) // Set { 1, 2 }
//    ^?

const encoded = idsSchema.encode(new Set([1, 2])) // [1, 2]
//    ^?
```

`kv.set()` automatically filters out elements that parse to `undefined` from the output set by default.
If you need to preserve `undefined` elements, use `kv.looseSet()` instead:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
const ids = kv.set(kv.int()).parse(['1', 'invalid', '3']) // Set { 1, 3 }
//    ^?

const looseIds = kv.looseSet(kv.int()).parse(['1', 'invalid', '3']) // Set { 1, undefined, 3 }
//    ^?
```

Chainable filters:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.set(kv.int()).nonempty()   // alias: .min(1)
kv.set(kv.int()).min(1)
kv.set(kv.int()).max(5)
kv.set(kv.int()).size(3)
```

Mutating transforms:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.set(kv.int()).slice(0, 10)
```

#### `kv.record(key, value)` [#record]

Object schema whose keys and values are (de)serialized through schemas.

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
const cacheSchema = kv.record(kv.string(), kv.int())

const cache = cacheSchema.parse({ a: '1', b: '2' }) // { a: 1, b: 2 }
//    ^?
```

With an [enum](#enum) key schema:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
const userSchema = kv.record(kv.enum(['id', 'name']), kv.string())

const user = userSchema.parse({ id: '42', name: 'Alice' })
//    ^?
```

`kv.record()` requires **all** enum keys to be
present (missing keys parse to `undefined` values).
Use `kv.partialRecord()` to allow missing keys:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
const userSchema = kv.partialRecord(kv.enum(['id', 'name']), kv.string())

const user = userSchema.parse({ id: '42', name: 'Alice' })
//    ^?
```

#### `kv.map(key, value)` [#map]

Like [`kv.record()`](#record), but produces a [`Map`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Map).

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
const votesSchema = kv.map(kv.string(), kv.int())

const votes = votesSchema.parse({ a: '1', b: '2' }) // Map { 'a' => 1, 'b' => 2 }
//    ^?

const encoded = votesSchema.encode(new Map([['a', 1]])) // { a: 1 }
//    ^?
```

### Wrappers & combinators [#wrappers-combinators]

All schemas expose these chainable methods:

#### `.default(value, options?)` [#default]

Falls back to `value` when parsing yields `undefined`. The default can be a
plain value or a factory function (called per parse).

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
const loosePage = kv.index().parse('1')
//    ^?

// [!code word:default]
const page = kv.index().default(0).parse('invalid') // 0
//    ^?
```

By default, when the state **equals** the default, the stored value is
cleared, so defaults never end up written to the URL or cookies:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
const pageSchema = kv.index().default(0)

const encoded = pageSchema.encode(0) // undefined, default value stays internal
//    ^?
```

To opt out of clearing pass `{ clearOnDefault: false }{:ts}`:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
// [!code word:clearOnDefault]
const pageSchema = kv.index().default(0, { clearOnDefault: false })

const encoded = pageSchema.encode(0) // 0, default value is written to storage
//    ^?
```

`.default()` checks equality using [`Object.is()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Object/is)
by default. For custom equality checks (e.g. for arrays/objects), pass a custom `isDefault` function:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.array(kv.string()).default([], {
  // [!code word:isDefault]
  isDefault: (value, defaultValue) => value?.length === defaultValue.length
    && value.every((v, i) => v === defaultValue[i]),
})
```

#### `.prefault(value, options?)` [#prefault]

Unlike [`.default()`](#default), `.prefault()` doesn't stop the parsing process
to eagerly return a default value, when the input is `undefined`, but instead
the default value is given as an **input** for the wrapped schema.

Use it when you want it to go through transforms, or when the default value is easier to
express in its stored form:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
// [!code word:prefault]
const date = kv.isoDateToDate().prefault('2024-01-01')
date.parse(undefined) // Date('2024-01-01')
```

#### `.optional()` [#optional]

Makes a schema _optional_ (allows `undefined` to pass through):

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
// [!code word:optional]
const schema = kv.string().default('').optional()

const value = schema.parse(undefined) // undefined
//    ^?
```

#### `.nullable()` [#nullable]

Makes a schema _nullable_ (allows `null` to pass through):

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
// [!code word:nullable]
const schema = kv.string().default('').nullable()

const value = schema.parse(null) // null
//    ^?
```

#### `.nullish()` [#nullish]

Makes a schema _nullish_ (both [optional](#optional) and [nullable](#nullable)):

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
// [!code word:nullish]
const schema = kv.string().default('').nullish()

const value = schema.parse(null) // null
//    ^?
```

#### `.singular(index?)` [#singular]

Picks one element when the raw value is an array:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.int().parse(['1', '2']) // undefined, because the schema expects a single value
// [!code word:singular]
kv.int().singular().parse(['1', '2']) // 1
```

Defaults to the first element. Pass a negative index (via [`.at()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/at) semantics)
or a function for custom picking:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.int().singular(-1).parse(['1', '2'])    // 2
kv.int().singular(arr => arr.length - 1)   // last element
```

Useful for interfaces that allow repeated keys (e.g. search params) when you only
care about one value:

<switch>
  <case react vue>
```ts
useSearchParams('page', kv.index().singular())
```
  </case>
  <case next-pages>
```ts
useRouterQuery('page', kv.index().singular())
```
  </case>
  <case vue-router nuxt>
```ts
useRouteQuery('page', kv.index().singular())
```
  </case>
</switch>

#### `kv.json(schema, options?)` [#json]

JSON string to typed value. Parses with [`JSON.parse()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/JSON/parse),
then validates the result against the inner schema. Encodes with
[`JSON.stringify()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/JSON/stringify).

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
const settingsSchema = kv.object({
  theme: kv.enum(['light', 'dark']).default('light'),
})

const jsonToSettings = kv.json(settingsSchema)
//                        ^^^^

const settings = jsonToSettings.parse('{"theme":"dark"}') // { theme: 'dark' }
//    ^?

const encoded = jsonToSettings.encode({ theme: 'dark' }) // '{"theme":"dark"}'
//    ^?
```

#### `.pipe(schema)` [#pipe]

Chains two schemas: `b` parses `a`'s output. Encoding runs in reverse
(`b` encodes first, then `a`).

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
const settingsSchema = kv.object({
  theme: kv.enum(['light', 'dark']).default('light'),
})

const base64urlToSettings = kv.base64url()
// [!code word:pipe]
  .pipe(kv.json(settingsSchema))

const settings = base64urlToSettings.parse('eyJ0aGVtZSI6ImRhcmsifQ') // { theme: 'dark' }
//    ^?

const encoded = base64urlToSettings.encode({ theme: 'dark' }) // 'eyJ0aGVtZSI6ImRhcmsifQ'
//    ^?
```

#### `.transform(fn)` [#transform]

Pipes the schema into a bidirectional transformation.

A bare function applies to both directions and its output type **must** be assignable to the input type:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
const tagsSchema = kv.looseArray(kv.string())

const looseTags = tagsSchema.parse(['a', {}, 'c']) // ['a', undefined, 'c']
//    ^?

// [!code word:transform]
const tags = tagsSchema.transform(arr => arr?.filter(i => i !== undefined)).parse(['a', {}, 'c']) // ['a', 'c']
//    ^?
```

For asymmetric transforms, pass `{ decode, encode }{:ts}`:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
const csvSchema = kv.string().transform({
  decode: v => v?.split(',').filter(Boolean),
  encode: v => v?.join(','),
})

const values = csvSchema.parse('a,b,c') // ['a', 'b', 'c']
//    ^?

const csv = csvSchema.encode(['a', 'b']) // 'a,b'
//    ^?
```

#### `kv.preprocess(def, schema)` [#preprocess]

Transforms the **raw input** before the schema parses it, and the raw output
after encoding. Since the preprocessor is expected to handle arbitrary raw
storage values, its `decode` input type is `unknown` by default:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
const fromCsv = kv.preprocess(
  {
    decode: (raw) => String(raw ?? '').split(','),
    //       ^?
    encode: (values) => values?.join(','),
  },
  kv.array(kv.string()),
)

fromCsv.parse(3.14) // ['3.14']
fromCsv.parse('a,b,c') // ['a', 'b', 'c']
fromCsv.encode(['a', 'b']) // 'a,b'
```

To narrow the input type and get proper typing, annotate it explicitly:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
const fromCsv = kv.preprocess(
  {
    decode: (raw: string | undefined) => raw?.split(','),
    encode: (values) => values?.join(','),
  },
  kv.array(kv.string()),
)

// @errors: 2345
fromCsv.parse(3.14)
fromCsv.parse('a,b,c') // ['a', 'b', 'c']
fromCsv.encode(['a', 'b']) // 'a,b'
```

#### `.overwrite(def)` [#overwrite]

Transforms the output in place (after parse and before encode) **without
changing the schema's types**. This allows you to transform a value while
keeping access to the original schema's methods and properties.

A bare function applies to both directions and
must be safe to run on its own output (idempotent):

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.string()
// [!code word:overwrite]
  .overwrite(v => v.padEnd(25, '.'))
  .trim()
  .toLowerCase()
```

Pass `{ decode, encode }{:ts}` to transform each direction separately:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
kv.int()
  .overwrite({
    decode: v => v - 1,
    encode: v => v + 1,
  })
  .min(0)
```

#### `.refine(check, fallback?)` [#refine]

Keeps values passing `check`. The check runs in **both** directions.
Rejected values fall back to `undefined` by default:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
// [!code word:refine]
const ratingSchema = kv.int().refine(v => v >= 1 && v <= 5)
ratingSchema.parse('9') // undefined
```

You can specify a custom fallback value to use when the check fails as a second argument
(which is required, if the output type of the inner schema doesn't allow `undefined`):

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
const clampedIntSchema = kv.int().default(0).refine(v => v <= 10, 10)
//                                                                ^^
clampedIntSchema.parse('99') // 10
```

This is what powers built-in chainable filters (`.min()`, `.max()`, etc.).

#### `kv.custom(def)` [#custom]

Builds a schema from plain `parse`/`encode` functions:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
const stringToEvenNumber = kv.custom({
  parse: (value: string) => {
    const n = Number(value)
    return Number.isInteger(n) && n % 2 === 0 ? n : undefined
  },
  encode: (value: number | undefined) => value != null ? String(value) : undefined,
})
```

Use it if you want to integrate `kvantjs/schema`'s built-in [wrappers & combinators](#wrappers-combinators)
with your own parsing logic.

#### `.apply(fn)` [#apply]

Passes the schema to a function and returns its result. Useful for custom
reusable combinators:

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
const bounded = (s: kv.KvantNumber) => {
  return s.clamp(0, 100).step(5)
}

// [!code word:apply]
kv.number().apply(bounded)
```

### Type utilities

```ts twoslash
import * as kv from 'kvantjs/schema'
// ---cut---
const page = kv.index().default(0)

// Output type (state), alias: `kv.infer`
type Output = kv.output<typeof page>
//   ^?

// Stored input type (what encode() returns)
type Input = kv.input<typeof page>
//   ^?

// Raw storage type (what parse() accepts, unknown by default for most schemas)
type RawInput = kv.rawInput<typeof page>
//   ^?
```

`kv.KvantType<Output, Input, RawInput>{:ts}` is the fluent interface every schema
implements. You can extend it when typing your own schema factories.
